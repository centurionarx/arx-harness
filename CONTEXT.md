## Product decisions and remaining operation

Identity, authorization, and indexes live in the server database. Session histories use private JSONL logs, and each project has persistent isolated filesystem storage on the server. A USER accesses their own projects and content. MASTER-ADMIN creates and releases users and modules without access to user project contents. Resend is the selected recovery-email provider. The bootstrap administrator account is a required, validated configuration value (`bootstrapAccount`, username and email) in the integrated source. A missing or invalid value fails at load, and bootstrap refuses to create a second MASTER-ADMIN; an independent re-review passes.

AUTH is not accepted or activated by this documentation phase. Remaining work is recorded in the staging status, plan and receipts. The accepted AUTH implementation reaches this repository only through a final pull request after integrated acceptance and independent reviews pass. Public access, real account bootstrap, mail delivery, migration, deployment, and physical worker isolation remain operating steps with their own evidence and authority.
