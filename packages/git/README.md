# Git

The [repository](repository/README.md) BFF exposes registered local workspace identity, independent status sides, and complete read-only comparisons through generated Typert Remote methods. The [repository sidebar](../client/ui-repository/README.md) owns selection and display; no Agent or model request is involved.

This family runs managed Git only against validated host-local filesystem and subprocess providers. Unsupported repository indirections or executable filters fail explicitly. The [GitHub service](github/README.md) separately owns explicitly configured credentials, private human PAT authorization, and read-only account/repository discovery. Default startup is unconfigured. Neither package clones repositories or stages, commits or pushes changes.
